# 🧮 Minha Calculadora em Python

Esse é o meu primeiro projeto de programação em Python, feito durante as aulas da **Imersão Alura** com a ajuda do **Google AI Studio**!

---

## 📝 Respostas sobre o código

### 1. Quais são os principais componentes e a estrutura do código?
O programa funciona em etapas bem simples:
* **Entrada de dados:** Usei o `input()` para pedir os números e a operação ao usuário. Como o Python lê tudo como texto, usei o `float()` para transformar esses textos em números de verdade (e aceitar vírgulas/pontos).
* **Menu simples:** Mostro na tela as opções de conta que a pessoa pode escolher (`+`, `-`, `*`, `/`, `**`).
* **Estrutura de decisão:** Usei o `if`, `elif` e `else` para o programa entender qual símbolo a pessoa digitou e fazer a conta certa.

### 2. Como funcionam as operações e a lógica de decisão?
O programa testa o símbolo que foi digitado:
* Se for `+`, ele soma.
* Se for `-`, ele subtrai.
* Se for `*`, ele multiplica.
* Se for `/`, ele divide os dois números.
* Se for `**`, ele calcula a potência.
* Se a pessoa digitar qualquer outro símbolo, cai no `else` e o programa avisa que aquela opção não existe.
